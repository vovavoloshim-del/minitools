# MiniTools — Корисні міні-інструменти

Набір безкоштовних онлайн-інструментів, які можна монетизувати.

## Що всередині

- Калькулятор середнього балу
- Генератор паролів
- Текстові інструменти (лічильник, регістри)
- Генератор QR-кодів
- Конвертер одиниць
- Калькулятор відсотків
- Таймер Помодоро

## Як запустити локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Як задеплоїти безкоштовно (рекомендовано)

1. Зареєструйся на [Streamlit Cloud](https://share.streamlit.io)
2. Залий код на GitHub
3. Підключи репозиторій — сайт буде працювати онлайн безкоштовно

## Як заробляти

- Підключи Google AdSense (коли набереш трафік)
- Додай Pro-функції (безлімітні генерації, збереження історії тощо)
- Роби кастомні версії інструментів під замовлення
- Просувай у TikTok/Telegram/Instagram як «корисний сайт для школярів»
